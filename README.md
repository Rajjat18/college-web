# ABC College Website

A modern, responsive college website built using HTML5, CSS3, JavaScript, and Bootstrap 5.

## Features

- Responsive Design
- Sticky Navigation Bar
- Smooth Scrolling
- Hero Section
- About College
- Courses Section
- Faculty Section
- Campus Gallery
- Contact Form
- Footer
- Bootstrap 5
- Google Fonts (Poppins)
- Bootstrap Icons

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
